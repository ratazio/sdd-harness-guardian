Use this file only for stable bundle-level memory.

## Stable principles

- Spec is the source of truth for intent.
- Harness is the source of truth for execution conditions.
- Skills define reusable methods.
- Workflows define sequencing.
- Rules define constraints.
- Artifacts prove outputs.
- Evaluator must be separate from builder.
- Critical soft rules need hard mirrors.
- Repeated errors become ratchet entries.
