**Builder:** Codex / implementation builder  
**Date:** 2026-08-27  
**Status:** approved — evaluate_t002_013, 2026-08-27

## Delivered increment

`BriefParser` now separates rendered markup from `script`, `style`, and
`template` subtrees; only non-empty rendered IDs enter the uniqueness
inventory. The v2 provenance stage reports every repeated rendered ID by name
and rejects material element/text/declaration/processing-instruction content
after the final rendered `</html>`. Comments and whitespace remain allowed.

## Focused controls

The focused suite now covers known and arbitrary duplicate rendered IDs; an
actual repeated `coverage-register` ID inside `template` plus inert
script/style/literal-close controls; rendered tag/text/DOCTYPE/processing-tail
negatives; permitted comment/whitespace tail; and a body/tail sentinel that
must never occur in the diagnostic. An initial `<!tail>` probe
was correctly found to be parsed as a comment by `HTMLParser`, so the
declaration control uses `<!DOCTYPE html>` instead.
