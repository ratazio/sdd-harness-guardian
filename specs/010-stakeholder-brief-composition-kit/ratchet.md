# Ratchet: 010-stakeholder-brief-composition-kit

If implementation discovers a shallow or decorative projection, add a
regression fixture that captures the source shape and verifies the prevention
without turning prose judgement into a score.

Initial prevention targets:

| Failure | Future guardrail |
|---|---|
| Unsupported child diagram | Source locator and independent trace; rich/sparse comparison fixture. |
| Generic task title only | Task card fixture exposes all non-empty task fields. |
| Empty technical rows in non-software work | Sparse/non-software fixture verifies omission or owned material question. |
| Flat impact/coverage loses semantics | Semantic equivalent and narrow/print manual check. |
| Client branding leaks into generic kit | Negative profile-selection fixture. |
| Populated tasks/ACs disappear behind generic Execution/Validation copy | Source-to-render parity fixture plus negative scaffold lifecycle case. |
