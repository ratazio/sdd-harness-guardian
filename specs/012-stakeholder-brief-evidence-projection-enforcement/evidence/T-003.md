## Delivered increment

`scripts/validate_human_visibility.py` now applies the T-001-approved grammar
only to v2 initiatives after the normal brief/gate checks:

- extracts `IR-*` IDs only from the first column of Markdown table rows in
  `impact-map.md`, then requires each in the rendered `#impact` panel;
- extracts normalized `METHOD /api/...` tokens only from API/contract-headed
  tables or backticked lists, or tables explicitly headed `Route`/`Method` in
  `plan.md`, then requires each in `#architecture` or `#validation`;
- emits a source, missing identifier and required-view diagnostic for each
  omission; and
- runs before freshness/baseline completion, while retaining v1 behavior and
  no-risk/no-API v2 behavior.

The parser deliberately does not interpret narrative mentions, unrelated
tables, arbitrary list items, routes outside the approved grammar, or whether
the surrounding explanation is decision-useful. Those remain human-review
responsibilities.
