## Canonical grammar decision (U-001)

| Source | Supported future inventory form | Normalization / false-positive boundary |
|---|---|---|
| `impact-map.md` | A Markdown table row whose first data cell is `IR-` followed by an alphanumeric identifier, optionally containing `_` or `-`. | Only first-column table IDs are material. Narrative mentions such as `IR-999`, other table columns and `R-*` do not create an obligation. |
| `plan.md` | An uppercase HTTP method (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `HEAD`, `OPTIONS`) plus a `/api/…` path in any Markdown table under an `API`/`contract` heading (for example, `Endpoint`) **or** a table explicitly headed `Route`/`Method`; a backtick-started list item is accepted only under an `API`/`contract` heading. | Query strings are stripped; the normalized token is `METHOD /api/path`. Generic prose, unrelated tables and list items outside an explicit API/contract heading do not create an obligation. |

This accepts different domains, versions, HTTP methods and colon/brace route
parameters while deliberately avoiding a generic Markdown/prose parser. It is
the bounded answer to U-001: additional source syntax needs a new fixture and
independent review before it becomes a deterministic obligation.
