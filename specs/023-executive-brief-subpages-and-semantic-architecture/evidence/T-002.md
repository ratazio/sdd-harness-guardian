## 1. Implementation summary

The reusable offline shell now treats every decision view as an internal route
(`?view=scope`, `?view=architecture`, and so on), rather than a primary
navigation anchor. With progressive enhancement, activating a route hides all
other main-region routes, sets `aria-selected` and `aria-current`, moves focus
to the newly opened domain when activated, and creates a browser-history entry.
Back/forward restore the corresponding complete route. Without JavaScript, the
same ordinary links load the one HTML and all source-order sections remain
available; print expands every route.

The layout is intentionally more vertical: each route has its own minimum
reading territory on wide screens, the navigation remains available while a
reader moves through that territory, and narrow screens return it to normal
flow. No avatar, login treatment, remote font, remote asset, new canonical
source, or change to existing Guardian skills/agents was introduced. The
Pearson profile remains an explicit local opt-in; this task changes the shared
shell mechanics, not the canonical Markdown authority or a real brief's
editorial content.
