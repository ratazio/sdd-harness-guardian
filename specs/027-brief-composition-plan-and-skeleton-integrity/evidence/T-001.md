separate from coverage mapping but remains in the same canonical document. It
captures thesis/audience, global relationships, all eight routed surfaces,
relationship/form/reason, repeated source-defined components,
absence/discovery and closing actions. The composition and review guidance now
requires a distinct pre-skeleton `APPROVE`/`REVISE` assessment with the
canonical recovery chain.

mock run was changed.

plan for a decision-ready brief.

workflow and reviewer contract define what must be decided before the skeleton
is copied, while preserving source-backed N/A/discovery and agentic form choice.  
**Expected artifact/behavior produced:** reviewers can return `REVISE` for a
plan missing narrative/relationship/form/closure before any skeleton exists.
