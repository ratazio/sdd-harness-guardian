## Implementation summary

Added the smallest deterministic hard mirror for the enriched stakeholder brief.
`scripts/validate_bundle.py` now owns a pure helper that checks four stable,
unconditional section IDs (`decision-snapshot`, `scope`, `validation`,
`decision`), four canonical source `href`s and the expected template/rendered
placeholder state. The validator uses it against the source template.

`scripts/smoke_test_scaffolder.py` uses the same helper against a newly
scaffolded feature brief and exercises three isolated, in-memory negative cases.
No conditional visual ID is required; no content quality, word count or visual
judgment is automated.

**Outcome served:** consumers receive a structurally usable default brief while
meaning and visual value remain a short Spec Guardian review.  
**Demonstrable increment:** missing stable structure, an unresolved scaffold
marker or a missing canonical source link now fails with an exact reason.

## Scope and residual risks

- The helper intentionally accepts only exact local source hrefs established by
  the template; if their format changes, the template and check must change
  together.
- The helper intentionally does not reject generic authoring instructions or
  assess visual/prose quality. Those remain semantic review responsibilities.
- Architecture, impact and flow are deliberately excluded from required IDs
  because their relevance is conditional.
