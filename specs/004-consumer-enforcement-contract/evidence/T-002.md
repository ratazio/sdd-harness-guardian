## Independent evaluation

The evaluator rejected the first fixture because it used a synthetic SHA and
injected a validator. The revised fixture uses `guardian-lock.json` placeholders
materialized with a local repository and real SHA; `install_guardian.py` clones,
checks out detached commit and verifies it. The workflow invokes that installer
before validation, so the wrapper runs only after the lock has been materialized.
This was approved under AC-006.

## Boundary and residual risk

This is a tested Factory output contract, not a change to Agentic Factory
itself. Each Factory template still needs to choose its native task-runner/CI
adapter and materialize an appropriate repository URL and immutable commit.
