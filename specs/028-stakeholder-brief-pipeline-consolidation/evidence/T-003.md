**Builder:** Codex (builder)

**Limite:** não houve deploy, rede externa, autenticação ou validação mobile.

## Contrato implementado

O preview de revisão é loopback HTTP, não `file:`. O contrato de renderização
e de Human Visibility exige `Preview URL: http://127.0.0.1...` e
`Preview environment:` quando uma revisão de qualidade pretende alegar
aprovação. A revisão não aprovada continua possível quando há candidate
rastreável, sem afirmar Human Visibility ou Tasks Ready.

Cada URL usa `?view=scope|architecture|impact|execution|validation|evolution|decision|coverage`.
O JavaScript do skeleton mostra exatamente um `tabpanel`, sincroniza a aba
selecionada, histórico e teclado. Sem JavaScript, a alternativa é leitura
honesta contínua, declarada como não equivalente às subpáginas desktop.

## Prova de superfície

Com o servidor loopback ativo, a auditoria de navegador percorreu 64 URLs:
oito rotas para cada M001–M008. M003 é o piloto fresco em
`20260902-spec028-autonomous-r4`; os demais sete cenários estão em
`20260902-spec028-matrix-r1`.

Em **64/64**, o resultado foi:

| Oracle | Resultado |
|---|---|
| painéis visíveis | exatamente um |
| painel visível | o mesmo ID solicitado em `?view=` |
| aba selecionada | exatamente `tab-<view>` |
| placeholder de scaffold visível | nenhum |

Exemplo reproduzível:

```text
http://127.0.0.1:4173/testes/mock-runs/20260902-spec028-matrix-r1/m007-kiosk/specs/001-accessible-public-kiosk/stakeholder-brief.html?view=validation
```
