# Ratchet — SPEC 025

## R-025-001 — Do not present a reference generator as the delivery path

**Trigger:** a visual reference omits material task, validation, impact or
decision content because it reads a compact code fixture rather than canonical
initiative Markdown.  
**Check:** delivery candidates carry a reviewed `plan.md` composition map, slot
continuity and source/task/proof projections before promotion.  
**Owner:** Guardian maintainers.  
**Consequence:** block promotion; repair map/candidate and request distinct
review. Do not patch only a screenshot or HTML card. If a decision genuinely
requires the report before editorial repair, record a v3 visible, hash- and
manifest-bound exception with owner, risk, expiry and next action; it is not a
Human Visibility or Tasks Ready pass.
