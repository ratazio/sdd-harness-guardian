# Brief candidate inheritance fixtures

`test_brief_candidate_inheritance.py` materializes these fixtures from the
current vendor-neutral template so their shell fingerprint always follows the
approved skeleton:

- **positive / in situ:** physical skeleton copy, lifecycle/base binding and
  source-backed replacement inside declared slots;
- **negative / parallel:** a compact page carrying the same base hash, eight
  route IDs and familiar navigation class, but without the copied stylesheet,
  behavior or immutable shell.

The fixture intentionally contains no product domain, Markdown source or
visual-quality assertion. It exercises lineage only.
