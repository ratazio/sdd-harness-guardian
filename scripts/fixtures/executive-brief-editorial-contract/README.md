# Executive brief editorial-contract fixtures

These fixtures calibrate the SPEC 023 T-001 map contract against three
different source situations. They do not choose a diagram, judge prose quality,
classify materiality, or approve a brief automatically. The fixtures preserve
what a distinct reviewer must be able to inspect.

| Case | Source situation | Required honest disposition |
|---|---|---|
| `learning-release` | Material product architecture names a learner shell, publishing contract and entitlement guard, including an internal learner-shell boundary. | Source-backed topology/change map/scale and a bounded learner-shell zoom. |
| `reservoir-operations` | A physical recovery procedure has state transitions and an operations owner, but no software architecture. | Operational relationship; no invented frontend or software topology. |
| `missing-internal-detail` | Source names only a macro gateway and explicitly lacks its interior. | Explicitly unowned discovery; no fabricated internal zoom or false zero. |

The companion test verifies paths, locators, source hashes, declared
dispositions and reviewer independence only. A discovery records owner/path
when its source supports them; otherwise it records their explicit absence plus
the missing fact and decision impact. The test deliberately does not decide
whether an explanation is sufficiently executive.
